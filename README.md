# HealthGuard AI Data Science Portfolio

This repository is now Streamlit-first and focused on the data science profile you described.

It demonstrates:

- Python data work with pandas, NumPy, matplotlib, and seaborn
- Core ML concepts such as regression, classification, and clustering
- Model evaluation with accuracy, precision, recall, and AUC-ROC
- Hands-on scikit-learn preprocessing and modeling
- A Kaggle-style problem statement and solution anatomy

## Launch

```bash
pip install -r requirements.txt
streamlit run app.py
```

Or run:

```cmd
.\start_app.bat
```

## Kept in scope

- `app.py` for the Streamlit interface
- `src/` for preprocessing and the ML pipeline
- `data/` for the dataset
- `requirements.txt` for Python dependencies

The frontend and backend Node stack are no longer part of the project.
